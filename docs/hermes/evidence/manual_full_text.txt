===== PAGINA 4 =====
 
 
Barra de Botones 
 
Es la fila de botones que se encuentra en la 
 parte superior de la pantalla, 
proporciona una serie de funciones y comandos, facilitando acc esar, modificar, 
buscar, anular y eliminar la información. 
 
 
 
Nuevo: Iniciar un nuevo documento o nuevo registro, ésta acción se 
puede ejecutar con las teclas Ctrl+N. 
Guardar: Graba los datos del documento o registro ésta acción se puede 
ejecutar con las teclas Ctrl+G. 
Modificar: Activa los campos para modificar registro activo, ésta acción 
se puede ejecutar con las teclas Ctrl+F2. 
Eliminar: Elimina registro activo o Anula el documento activo, ésta acción 
se puede ejecutar con las teclas Ctrl+E. 
Buscar: Buscar registros o documentos, ésta acción se puede ejecutar 
con las teclas Ctrl+f3. 
Primero: Permite desplazarse hasta el primer registro o documento, ésta 
acción se puede ejecutar con las teclas Ctrl+F5. 
Anterior: Permite desplazarse al anterior re gistro o documento, ésta 
acción se puede ejecutar con las teclas Ctrl+F6. 
Siguiente: Permite desplazarse al siguiente registro o documento, ésta 
acción se puede ejecutar con las teclas Ctrl+F7. 
Ultimo: Permite desplazarse hasta el último registro o docum ento, ésta 
acción se puede ejecutar con las teclas Ctrl+F8. 
Imprimir: Imprime documento activo, ésta acción se puede ejecutar con 
las teclas Ctrl+I. 
Deshacer: Deshacer cuando se ha presionado el botón nuevo, o 
modificar. 
Cerrar: Permite cerrar el documento. 
Actualizar: Actualizar formulario activo esto por si hay cambios en otro 
formulario que afecte a este.
